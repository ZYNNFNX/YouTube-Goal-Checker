# 🎯 YouTube Goal Checker

**Set goals. Track progress. Stay consistent. Grow your audience.**

YouTube Goal Checker is a creator-focused application designed to help content creators set goals, stay motivated, and work toward growth across **YouTube, TikTok, and Instagram**.

Whether you're just starting your creator journey or building your online presence, use this project to stay focused, plan ahead, and keep moving toward your goals.

## ✨ Features

- 🎯 **Goal Setting** — Define goals for your content creation journey.
- 📈 **Progress Tracking** — Keep track of your progress toward your targets.
- 📱 **Multi-Platform Support** — Designed for YouTube, TikTok, and Instagram creators.
- 💡 **Creator Guidance** — Get guidance to help you stay focused on your goals.
- 🔥 **Motivation** — Stay encouraged and consistent throughout your journey.
- 🎨 **Modern Interface** — Built with a modern web development stack.

## 🛠️ Tech Stack

- **React 19** — User interface
- **TypeScript** — Type-safe development
- **Vite** — Development server and build tooling
- **Tailwind CSS** — Styling
- **Express** — Server
- **Google GenAI SDK** — AI integration support

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/ZYNNFNX/YouTube-Goal-Checker.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd YouTube-Goal-Checker
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Configure environment variables**

   If the application requires environment variables, create a `.env` file using the provided example:

   ```bash
   cp .env.example .env
   ```

   Add the required values to your `.env` file according to the project's configuration.

5. **Start the development server**

   ```bash
   npm run dev
   ```

   Open the local URL displayed in your terminal.
